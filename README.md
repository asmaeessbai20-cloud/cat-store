# 🐱 Cat Store

A small online cat store built with **React** as a study project (OFPPT – Front-end development).

## Features
- Home page with a hero background
- Products list with name, price and details button
- Product page with quantity and live total
- Cart with delete button, item count in the navbar and grand total
- Routing with React Router

## Tech
- React 18
- React Router
- Vite
- CSS

## Run locally
```bash
git clone https://github.com/asmaeessbai20-cloud/cat-store.git
cd cat-store
npm install
npm run dev
```
Then open http://localhost:5173
